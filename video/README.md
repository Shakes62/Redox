# REDOXDESIGNX film

A motion film made with [Remotion](https://www.remotion.dev), with the same voice, sound, mix and motion
system as the Plugg films (see `QUALITY_PLAYBOOK.md`; nothing in the audio chain was changed).

| File | For |
|---|---|
| `out/redoxdesignx-how-to-order-9x16.mp4` | TikTok, Reels, Shorts, WhatsApp Status |
| `out/redoxdesignx-how-to-order-16x9.mp4` | YouTube, Facebook, the website |
| `out/redoxdesignx-how-to-order.en.srt` | Captions for YouTube, Facebook, LinkedIn, X |

## The story (about 99 seconds)

**The brand and the range:** the RD icon and the name · "Wear it plain. Print it loud." with the 230 GSM tee
cycling through its colours · pick your weight: every shirt from 230 to 320 GSM, lightest to heaviest, with
prices · the range: tees, raglans, long sleeves, the Summer Patch Tee and tracker caps in 19 colours · made
right: 100% compact cotton, boxy fit, true to size · bulk price (10+ for GH₵48.00 on the 230 GSM tee) · "Got a
design? We print it." on WhatsApp.

**How to order, on the store's real screens:** 1 open a shirt and tap a colour · 2 tap sizes, mix colours,
watch the total, Buy now · 3 checkout details (name, phone for SMS updates, email for the receipt) · 4 pick
your town from the real delivery list (161 places), the price shows, add a landmark · 5 review and tap Pay;
the film then *says* that Paystack opens (MoMo, card or bank, approve with your PIN). Paystack's own window is
not recreated, on purpose · 6 Order placed, and the confirmation SMS · 7 packing, the shipped SMS, the
delivery call, today or tomorrow, the track-order page · why REDOX · the end card.

One fictional order runs through it: Ama Mensah buys Wine L ×2 and Black XL ×1 of the 230 GSM Plain T-Shirt,
delivers to Madina, pays GH₵203.30 and gets order #RD-1250.

## Accuracy

- **The screens are the store's own.** The film imports the app's real CSS modules (`../src/**/*.module.css`,
  `../src/app/globals.css`), its icons and its helpers. `scripts/phone-css-loader.cjs` lays the CSS out exactly
  as on a 390pt phone, and the screens use the site's light theme. Only what is typed, tapped or scrolled
  comes from the film.
- **Products, prices, colours, GSM and bulk prices** come from the live catalogue (`src/catalog.json`), read
  through the store's own `product-display.ts` and `wholesale.ts`.
- **Every SMS is generated by the store's own code** (`buildOrderSms` in `src/lib/sms.ts`,
  `buildShippedSms` in `src/lib/shipping-sms.ts`), so it reads exactly like the real text. The sender is the
  Hubtel sender ID (`RedoxDesign`).
- **Delivery places, prices and the "today or tomorrow" note** are the live delivery settings.
- **Nothing third-party is faked:** no Paystack window, no PIN prompt, no phone keyboard, no call screen.
  Those steps are told in captions only.

## Update after the store changes

```bash
cd video
npm run photos        # fresh catalogue + delivery places from the database (read-only), photos downloaded
npm run render:all    # both videos, mastered to -14 LUFS, plus captions
```

If you change the narration (`scripts/vo.py`), run `npm run voice` first: the scenes follow the new timing.

## Commands

```bash
npm install
npm run voice          # narration + scene timing (python scripts/vo.py)
npm run studio         # live preview with a timeline
npm run render         # 9:16, mastered
npm run render:wide    # 16:9, mastered
npm run captions       # .srt
npx remotion still Screens out/screens.png               # every store screen side by side
SCALE=0.35 node scripts/stills.mjs Redox-Vertical out/v 300 900   # quick PNG previews of chosen frames
```

Judge the sound on the rendered MP4, not the Studio preview. Narration needs internet (edge-tts).
Remotion is free for individuals and companies of up to 3 people; check remotion.dev/license if the team grows.

## What to edit

| Change | File |
|---|---|
| On-screen words, the order in the story, audio switches | `src/script.ts` |
| Narration lines and voice | `scripts/vo.py`, then `npm run voice` |
| Film colours and fonts | `src/brand.ts` (the store's light-theme tokens) |
| Store screens | `src/ui/*` (markup only; the styles are the app's) |
| Scenes and their timing | `src/scenes/redox.tsx` |
| Sound effects | `src/FilmRedox.tsx` |
